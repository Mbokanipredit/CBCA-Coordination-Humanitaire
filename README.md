# CBCA: Humanitarian Coordination

Web platform for the **Communauté Baptiste au Centre de l'Afrique (3e CBCA) – Humanitarian Coordination**, a social and community-based organization operating under Ordinance n°170 of 12 June 1964 and active in education, health, development, and humanitarian action in the Democratic Republic of the Congo (DRC).

Through its Humanitarian Coordination, the CBCA is committed to rapid response to crises and natural disasters, easing the suffering of affected populations and supporting their recovery.

## Features

- "About the CBCA" presentation of the organization and its mission
- Highlighted impact figures (schools, health facilities, development centers)
- Overview of humanitarian and crisis response activities
- Responsive design for mobile and desktop
- Content available in French

## Getting Started

### Prerequisites

- A modern web browser
- Node.js 18+ or PHP 7.4+ (depending on your stack)

### Run locally

```bash
# Clone the repository
git clone https://github.com/Mbokanipredit/<repo-name>.git

# Move into the project folder
cd <repo-name>

# Install dependencies (if using Node.js)
npm install

# Start the development server
npm run dev
```

Then open [http://localhost:3000](http://localhost:3000) in your browser.

> For a PHP project, replace the last steps with `php -S localhost:8000`.
